# Change Log

All notable changes to the "sequoia" extension will be documented in this file.

## [1.32.0] - 2026-05-24

### Added

- **Sequoia Moonlight Light**, **Sequoia Monochrome Light**, and **Sequoia Retro Light** themes
- Dark variants renamed to **Sequoia Moonlight Dark**, **Sequoia Monochrome Dark**, and **Sequoia Retro Dark**
- Legacy theme names (**Sequoia Moonlight**, **Sequoia Monochrome**, **Sequoia Retro**) kept as aliases for existing installs
